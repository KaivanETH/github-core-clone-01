A standalone GitHub-compatible git forge in one Node 22 process: smart git HTTP (upload-pack protocol
v2 and receive-pack v0), the REST v3 API, the GraphQL v4 API and a Streamable-HTTP MCP endpoint, all
served from its own store — no git binary, no outside service, stdlib only.

## Run it

```sh
node main.ts
```
